# ui-asset-search

Cross-instance UI asset discovery, indexing, and search dashboard for Share Ventures.

Crawls all OpenClaw instances in the fleet, catalogs UI screenshots, images, dashboards, deployed links, and project names. Provides instant search + filtering.

## Features

- 🔍 Instant search across 5,000+ assets
- 🖥️ Dashboard, image, project, design, and link discovery
- 🏢 Filter by instance (9 OpenClaw instances)
- ⊞/☰ Grid and list views
- 🌙 Dark premium UI (Share Ventures Design System v2)

## Tech

- Next.js 14 (App Router)
- MongoDB (Azure Cosmos)
- Vercel deployment
- Daily automated crawl via OpenClaw cron
